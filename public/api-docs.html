🔌 API Documentation

SpendWise Personal - REST API Endpoints

Base URL: https://spendwise-personal.onrender.com/api

🔐 Authentication

POST /api/auth/register Đăng ký tài khoản mới
POST /api/auth/login Đăng nhập và nhận JWT token
GET /api/auth/me Lấy thông tin user hiện tại

💰 Ví tiền (Wallets)

GET /api/wallets Lấy danh sách ví
POST /api/wallets Tạo ví mới
PUT /api/wallets/:id Cập nhật ví
DELETE /api/wallets/:id Xóa ví

📊 Giao dịch (Transactions)

GET /api/transactions Lấy danh sách giao dịch (có filter theo tháng)
POST /api/transactions Tạo giao dịch mới
PUT /api/transactions/:id Cập nhật giao dịch
DELETE /api/transactions/:id Xóa giao dịch

🎯 Ngân sách (Budgets)

GET /api/budgets Lấy danh sách ngân sách
POST /api/budgets Tạo ngân sách mới
PUT /api/budgets/:id Cập nhật ngân sách
DELETE /api/budgets/:id Xóa ngân sách

🎁 Mục tiêu tiết kiệm (Savings Goals)

GET /api/goals Lấy danh sách mục tiêu
POST /api/goals Tạo mục tiêu mới
PUT /api/goals/:id Cập nhật mục tiêu
DELETE /api/goals/:id Xóa mục tiêu

📋 Sổ vay nợ (Debts)

GET /api/debts Lấy danh sách vay nợ
POST /api/debts Tạo khoản vay/nợ mới
PUT /api/debts/:id Cập nhật khoản vay/nợ
DELETE /api/debts/:id Xóa khoản vay/nợ

🔄 Thu/Chi định kỳ (Recurring)

GET /api/recurring Lấy danh sách giao dịch định kỳ
POST /api/recurring Tạo giao dịch định kỳ mới
PUT /api/recurring/:id Cập nhật giao dịch định kỳ
DELETE /api/recurring/:id Xóa giao dịch định kỳ

📂 Danh mục & Dashboard

GET /api/categories Lấy danh sách danh mục
GET /api/dashboard/summary Lấy tổng quan dashboard (thu/chi, biểu đồ, alerts)
